# Terminal and editor r7 — 2026-10-24

Terminal uses one VT surface and actual PTY byte input; the command field is gone. The default Coast shell owns inline ANSI editing, 32-entry history and completion. Enter, Backspace/Delete, arrows/Home/End, Ctrl-A/E/U/K/W, Ctrl-C at the prompt, Ctrl-D on an empty prompt, and Ctrl-L redraw are supported. Input is bounded at 511 bytes; oversize commands are rejected, not partially executed. Console invocation is preserved separately. Shell code restores cooked echo/signal settings before foreground children.

Verified guest behavior includes interactive child stdin, default-shell child Ctrl-C, nano raw edit/save/alternate-screen return, wrapped commands, resize during typing, 512-row bounded scrollback, Shift-PageUp/Down and background output preserving typed input. Asynchronous output can interleave visually with a prompt; Ctrl-L redraws it. Unicode scalar values are retained for selection/copy, but glyph coverage is limited to the existing mono atlas and missing glyphs display a fallback; wide/combining/CJK terminal layout and a complete xterm implementation are not claimed.

Terminal menu > Preferences (or Ctrl+,) opens one nonmodal owned child per Terminal. Drafts do not change live preferences. Apply commits to the active profile and stays open; Done applies and closes; Cancel, Escape or the close button discard unapplied drafts. Already-applied values remain. Parent close closes the child; parent minimize/workspace movement carries it. A draft captured for a different active profile cannot be applied; close/reopen to edit that profile. Palette, explicit text/background colors, opacity with backdrop blur, native font size, ANSI colors and the default shell are included. Existing sessions keep their shell. Preference files persist to the existing writable FAT configuration when available, otherwise within RAM for that boot; no host disk is attached by the default launch command. Terminal preferences are no longer a category in system Settings; the persisted field names are retained.

The image contains genuine GNU Bash 5.3.20 with bundled Readline, from existing hash/signature-verified GNU source plus 20 official patches. Raw Readline editing/history/Ctrl-U and builtin read pass in a guest. A Bash-launched sleep did not respond promptly to Ctrl-C; full foreground/job control and full-screen child compatibility remain experimental. The default Coast shell remains the tested route for reliably interruptible/full-screen programs. zsh/fish/Oh My Zsh are unbuilt, not proven impossible; see SHELL-DEPENDENCY-ASSESSMENT.md. No accounts, credentials, sudo or privilege enforcement changes were made.

The plaintext editor has compact labeled New/Open/Save/Save As, Undo/Redo, Find/Replace and Preferences controls, plus visible text size, tab width, spaces, automatic indent, line numbers and whitespace markers. Controls wrap at narrow widths and share geometry with hit-testing and the text viewport. Display preferences do not store formatting in files. Editing retains original UTF-8 and mixed LF/CRLF bytes except the explicitly edited range. Undo/redo is bounded to 64 edits and 1 MiB of history; failure to allocate undo storage preserves the document. Search is literal/case-sensitive, replacement is one selected match at a time. There is no rich formatting, spreadsheet model or soft-wrap setting; long lines retain horizontal scrolling. Existing checked saves and conflict refusal remain.

Code OSS M2 is an independent genuine upstream PieceTree CLI milestone on existing JavaScriptCore. `codeoss-core /home/user/example.txt` edits UTF-8 files with checked reads, stale-save conflicts, retained originals and no-clobber Save As. Guest RAM, actual disposable FAT32, read-only and interactive tests pass. It is not a full graphical VS Code workbench or an integration of PieceTree into the native Text Editor. See CODEOSS-M2-RELINK.md and /usr/share/codeoss/PORT-STATUS.txt.

Build GUI/shell with `make -C userland bin/gui bin/coast-sh`. The optional `tools/build_bash_readline.py --root PROJECT --build-root PROJECT_LOCAL_OUTPUT --jobs 2` rebuilds cached GNU sources offline without installing anything globally. Preserve the new release's source/notices, original Bash archive/patches/signatures, native integration objects and Code OSS/JSC corresponding-source/relink material. No upload/public distribution was performed.
