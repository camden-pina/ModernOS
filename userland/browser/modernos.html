ModernOS Browser

Powered by the native NetSurf 3.11 engine.

Browse the web or your files

Press Ctrl+L or use the address field to enter an HTTP/HTTPS address or a local file path. HTTPS verifies the server certificate using the bundled Mozilla CA certificates.

Controls

  • Alt+Left / Alt+Right: back and forward. F5 / Ctrl+R: reload.
  • Ctrl+N: a new native browser window. Wheel / Page Up / Page Down: scroll.
  • Follow links, fill forms, select text and use the page's own controls.
  • Open HTML, SVG, PNG, JPEG, GIF and BMP files directly from Files.

Available capabilities

Real HTML, CSS, DOM, PNG/JPEG/GIF/BMP/SVG images, antialiased FreeType fonts, and NetSurf's Duktape JavaScript support. Modern web APIs beyond this engine's support may not work.

IPv4 and DNS use the kernel's lwIP stack. The Intel e1000/e1000e driver supports the QEMU adapter; other network hardware needs its own driver. netinfo reports the actual link and address. Local documents work without an Ethernet connection.

Web pages run in a restricted browser process. Local files are available when you open them from Files or the address field. Downloads are saved in your Downloads folder.
