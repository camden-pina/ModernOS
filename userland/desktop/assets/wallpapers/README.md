# ModernOS sample wallpapers

These project assets were generated with the built-in imagegen tool for use as
sample desktop wallpapers. The original PNG images are packaged unchanged in
`/usr/share/wallpapers` inside the ISO's initramfs.

- `alpine-lake.png`: Alpine Lake, a quiet mountain lake at dawn.
- `desert-sunset.png`: Desert Sunset, sandstone dunes and mesas at sunset.

Settings also opens `/home/user/Pictures/Wallpapers` for personal wallpapers.
PNG, JPEG and uncompressed 24/32-bit BMP images are supported. Personal images
must remain at their saved paths for saved preferences to reload them.

## Generation prompts

### Alpine Lake

```text
Use case: stylized-concept
Asset type: sample wallpaper for the ModernOS desktop, named Alpine Lake.
Primary request: Create one polished landscape desktop wallpaper, wide 16:10 composition at approximately 1920x1200. A tranquil alpine lake with softly layered blue and teal mountains, pale early-morning mist, and a subtle sky glow reflected in still water.
Style/medium: refined atmospheric digital landscape illustration with smooth natural textures and gentle gradients, a professional operating-system wallpaper.
Composition/framing: broad panoramic scene, simple clean silhouette shapes, comfortable quiet areas behind desktop windows, no frame or inset.
Lighting/mood: calm and spacious, low visual noise.
Constraints: exactly one wallpaper filling the entire image; no text, logos, watermark, icons, UI or borders.
```
