From source to your system

brine search name finds packages and recipes. brine show name --community displays a recipe without running it.

After reviewing the checkout, brine install name --community builds as your normal user and authenticates installation through sudo.

Use votes, comments, out-of-date flags, and package requests to help maintainers keep Coast useful.
